# Frutiger Aero 2 · Web build

Браузерная сборка Godot для плеера CFUjam. GitHub Pages публикует корень ветки `main` по адресу `https://perrarancino.github.io/test/`.

Чтобы обновить игру, экспортируйте проект в Web с именем `index.html` и выключенным `Thread Support`. Замените файлы предыдущего экспорта в корне репозитория и отправьте их одним коммитом в `main`. После публикации GitHub Pages плеер CFUjam загрузит новую версию при следующем открытии страницы игры.
