# Frutiger Aero 2 · Web build

Браузерная сборка Godot для плеера CFUjam. Плеер скачивает `game.zip` напрямую из публичной ветки по умолчанию после нажатия «Запустить игру».

Чтобы обновить игру, экспортируйте проект в Web с именем `index.html` и выключенным `Thread Support`. Упакуйте файлы экспорта вместе с `index.html` в `game.zip` и отправьте его в корень ветки `main`. После обновления кэша GitHub браузер получит новый ZIP при следующем запуске.

GitHub Pages можно использовать как запасной вариант. Для этого обновите распакованные файлы в корне ветки и сохраните в `<head>` строку `<script src="https://morejam.ru/game-audio.js"></script>`, чтобы кнопка звука CFUjam управляла игрой внутри Pages.
